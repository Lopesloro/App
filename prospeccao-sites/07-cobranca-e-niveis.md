# Cobrança e níveis de entrega

> [!summary] Em uma frase
> Primeiro gerar valor percebido (análise + demonstração gratuitas, **com limites**), depois pedir compromisso: entrada de 10% para transformar a demo em projeto final.

## ✅ O que foi feito neste assunto

- [x] Decidido que os 10% **não** vêm antes da primeira demonstração (mudança sobre o rascunho original).
- [x] Entrada reposicionada: não é "taxa", é **reserva do projeto** (inicia personalização e versão final).
- [x] Definidos os **3 níveis de entrega** com fronteira clara entre grátis e pago.
- [x] Resolvido o dilema "construir antes ou depois do pagamento" com o **modelo híbrido**.
- [x] Registrada a regra de preço: vendemos **resultado comercial, não tokens** — custo baixo de produção não justifica preço baixo.
- [x] Nomenclatura fixada: **"demonstração gratuita" / "nova versão demonstrativa"** — nunca "site grátis".

## A entrada de 10%

```
Projeto:  R$ 2.000
Entrada:  R$ 200
Saldo:    R$ 1.800
```

A entrada serve para **reservar o projeto, iniciar a personalização e preparar a versão final**. Filtra curiosos: há uma diferença enorme entre "sim, gostei" e "sim, paguei R$ 200 para começar".

Depois que o cliente gostou da demo:

> "Para transformar essa demonstração em uma versão final e colocar tudo em produção, começamos com 10% de entrada."

## Os 3 níveis

| Nível | O que é | Custo |
| --- | --- | --- |
| 🟢 1 — Análise | "Encontramos estes problemas." | Gratuita |
| 🟢 2 — Demonstração | Nova versão para visualizar: página inicial, estrutura principal, alguns botões, identidade visual básica | Gratuita, **com limites** |
| 🟡 3 — Projeto final | Todas as páginas, conteúdo definitivo, formulários, integrações, domínio, SEO, analytics, ajustes, publicação | **Pago** |

> [!warning] Fronteira inegociável
> **Análise/demonstração ≠ desenvolvimento contratado.** Entregar site completo antes de cobrar = gente pegando o trabalho e desaparecendo (ver [[08-riscos]]).

## Modelo híbrido (antes × depois do pagamento)

| Antes do pagamento | Depois dos 10% |
| --- | --- |
| Análise | Site completo |
| Screenshot | Conteúdo refinado |
| Conceito | Funcionalidades |
| Versão demonstrativa limitada | Domínio, publicação, ajustes |

Isso protege a margem: gasta-se pouco com quem nunca compra, e a demo ainda é personalizada o bastante para vender.

## Recorrência (a ideia ainda melhor)

Depois de entregar, não encerrar a relação: vender um **"plano de evolução" mensal** — pequenas alterações, novas fotos, novos serviços, ajustes, melhorias mobile, SEO básico, monitoramento, correção de links, atualizações.

> [!tip] Mudança de negócio
> De "construí um site e acabou" para **"carteira de empresas pagando mensalmente"**.
