# Variações de abordagem (ângulos de oferta)

> [!summary] Em uma frase
> 18 ângulos catalogados sobre o mesmo princípio — **encontrar um problema real, mostrar o problema, entregar prova visual** — mais os tipos de lead A–H e as 5 melhores apostas para testar primeiro.

## ✅ O que foi feito neste assunto

- [x] 18 ângulos de oferta catalogados (lista abaixo).
- [x] Tipos de lead A–H definidos, cada um com abordagem própria (fim da mensagem genérica).
- [x] Ranking das **5 melhores apostas** definido.
- [x] Método de teste definido: 100 leads de um único segmento, 2–3 abordagens, medir o funil inteiro.

## Os 18 ângulos

| # | Ângulo | Ideia central |
|---|---|---|
| 1 | **Seu site no celular** | "Analisamos pelo celular e encontramos pontos que dificultam o contato." Concreto e fácil de demonstrar |
| 2 | **Antes e depois** ⭐⭐⭐⭐⭐ | "Montamos uma ideia de como poderia ficar." Venda vira comparação visual |
| 3 | **Perda de clientes** | Problemas de conversão (telefone escondido, formulário quebrado, sem CTA) — melhor que chamar o site de feio |
| 4 | **Teste de 30 segundos** | Diagnóstico com notas (mobile 4/10, contato 5/10…) — aparência profissional |
| 5 | **Concorrente está melhor** | Comparação local — usar com cuidado, nunca dizer "seu concorrente é melhor" |
| 6 | **Página inicial gratuita** | Refazer só a homepage como demo — reduz MUITO o custo; das primeiras a testar |
| 7 | **Landing page de campanha** | Página específica para um serviço (ex.: implante dentário) — conecta site a oferta comercial |
| 8 | **Página de WhatsApp** | Página cujo objetivo é `VISITANTE → WHATSAPP` — orientada a resultado |
| 9 | **Google → WhatsApp** | O site atual consegue levar do Google à conversa em segundos? Se não, há oferta |
| 10 | **Site que parece de 2015** | Campanha para sites muito antigos, sem ser ofensivo |
| 11 | **Site + Google Maps** | Inconsistências entre Google e site (telefone, horário, endereço, link quebrado) |
| 12 | **Site não transmite o tamanho da empresa** | "A empresa parece mais profissional do que o site transmite" — elogia a empresa, não ataca |
| 13 | **Site antigo → site premium** | Ticket alto (arquitetos, advogados, clínicas, B2B): aparência = confiança |
| 14 | **Mobile Upgrade** | Produto separado: só a versão mobile otimizada — menos trabalho, demo fácil |
| 15 | **Auditoria + demonstração** (favorita) | `GRÁTIS → diagnóstico → demonstração → ENTRADA → site completo → RECORRÊNCIA → manutenção` |
| 16 | **Manutenção automática** | Plano de evolução mensal — carteira recorrente (ver [[07-cobranca-e-niveis]]) |
| 17 | **Máquina de oportunidades** | Cada tipo de lead (A–H) recebe abordagem diferente |
| 18 | **As 5 melhores apostas** | Ranking para começar (abaixo) |

| H | Concorrentes com sites melhores |

## As 5 melhores apostas

1. 🥇 **Empresa boa + site ruim** — "a empresa parece profissional, mas o site não transmite isso."
2. 🥈 **Problema mobile** — "encontramos problemas na experiência pelo celular."
3. 🥉 **Antes/depois** — "encontramos alguns pontos e criamos uma alternativa."
4. **WhatsApp/conversão** — "o visitante encontra dificuldade para entrar em contato."
5. **Homepage demonstrativa** — "refizemos a página inicial como exemplo."

> [!important] Como testar
> Não vender tudo ao mesmo tempo. **100 leads de um único segmento**, divididos em 2–3 abordagens, medindo:
> **resposta → responsável → interesse → demonstração → pagamento → fechamento**
> O "problema" que faz o cliente levantar a mão vira o centro da máquina de aquisição.
