# Ideia original (rascunho)

> [!summary] Em uma frase
> Encontrar empresas com site desatualizado, falar direto com quem decide gastando o mínimo possível, e só usar IA pesada depois que houver interesse real.

## ✅ O que foi feito neste assunto

- [x] Rascunho original registrado por escrito (base de todas as conversas seguintes).
- [x] Definida a ordem: mensagem simples **antes** de gastar tokens (economia).
- [x] Definido que o Claude Code só entra **depois** da confirmação do interessado.
- [x] Definido que a entrega da demo é por link automático (GitHub Pages) com botões funcionando.
- [x] Definido o ponto de troca: quando o cliente aprova, **o agente para de falar e eu entro**.
- [x] Regras de comunicação promovidas a **não negociáveis** (ver abaixo).

## O rascunho

Captação de clientes que possuem sites desatualizados:

1. Busca pela **Apify** por sites desatualizados e que não funcionam bem.
2. App server manda **mensagem simples**, só para obter resposta, antes de gastar tokens.
3. Falar diretamente com o dono (depois refinado para **responsável pela decisão** — ver [[04-conversas-whatsapp]]).
4. Após confirmação, o **Claude Code** analisa o site antigo e o refaz de forma nova e realista — prioridade total para ficar **muito bom no celular**.
5. Segunda conversa já com o **link funcionando** (GitHub Pages, automático, botões operantes).
6. A partir daí o agente de IA **não fala mais** — nós entramos.
7. Cobrança: custo baixo para conversão rápida; **10% do valor antes de iniciar para valer** (refinado depois em [[07-cobranca-e-niveis]]).

## Regras de comunicação (não negociáveis)

> [!warning] Observações-chave do fundador
> - As mensagens devem ser sempre em forma **amigável** — não podemos parecer automáticos.
> - **Muito importante que as mensagens sejam curtas.**
> - **Estruturação 100% antes de qualquer lançamento.**
> - É muito importante que chegue uma **notificação para eu ver**, pois será tudo automático.
